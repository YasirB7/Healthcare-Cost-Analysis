##Healthcare Cost Analysis

This project analyzes a healthcare insurance dataset to identify key factors that influence medical costs. The analysis focuses on demographic and behavioral variables such as smoking status, BMI, region, and gender.

##Objectives
- Explore and understand the dataset
- Identify major cost drivers
- Visualize trends using charts
- Generate actionable insights

##Technologies Used
- Python
- Pandas
- Matplotlib

##Key Analysis
- Average charges by smoker status, region, and sex
- Correlation analysis between numerical variables
- Data visualization using bar charts, scatter plots, and boxplots

##Key Insights
- Smokers have significantly higher medical costs than non-smokers
- BMI shows a positive relationship with healthcare charges
- Regional differences in costs are present but less significant than smoking

##How to Run
1. Download or clone the repository
2. Open the project in PyCharm or another Python IDE
3. Run `healthcare_analysis.py`

##Dataset
- Insurance dataset used for healthcare cost analysis practice

##Project Purpose
This project demonstrates data analysis, visualization, and insight generation skills relevant to real-world healthcare analytics.
